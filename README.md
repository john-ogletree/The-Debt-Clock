# TDC - The Debt Clock 📊

A comprehensive, community-driven dashboard tracking global debt, living wages, job market indicators, DTC economics, and conflict costs. All data is embedded locally with real-time updates and zero external calls.

## What is TDC?

TDC (The Debt Clock) is a complete economic dashboard that visualizes key financial and economic metrics in one place. It features:

- **Global and national debt tracking** with live counters
- **Living wage benchmarks** across multiple countries
- **Job market indicators** including unemployment and job openings
- **DTC (Direct-to-Consumer) economics** data
- **Iran conflict cost tracker** with per-citizen breakdown
- **Opportunity cost calculator** showing what else these funds could support
- **Real-time counters** updating every second
- **Interactive charts** showing trends
- **Multi-language support** (English, Spanish, French, German, Arabic)

Everything runs locally. No server calls, no data collection, no tracking.

## Why Use TDC?

- **Community-Driven:** Built for transparency and public awareness
- **Local-First:** All data embedded, no external API calls
- **Real-Time:** Counters update live with economic estimates
- **Comprehensive:** Covers debt, wages, jobs, and conflict costs in one view
- **Transparent:** All sources are cited and verifiable
- **No Accounts:** No sign-ups, no logins, no data collection
- **Multi-Language:** Available in 5 languages
- **Exportable:** Download data as CSV or print the dashboard

## How to Use

1. **Open TDC** in your browser
2. **View the dashboard** with all metrics displayed
3. **Watch counters update** in real-time
4. **Explore charts** to see trends
5. **Use the "What If?" calculator** to model different scenarios
6. **Export data** or **print** the dashboard
7. **Pin cards** by clicking the 📌 button
8. **Switch languages** using the dropdown
9. **Toggle dark/light mode** with the theme switch

### Controls

| Control | Function |
|---------|----------|
| **Language Selector** | Switch between 5 languages |
| **Dark/Light Toggle** | Toggle theme |
| **CSV** | Export data as CSV |
| **Print** | Print the dashboard |
| **Reset** | Reset pinned cards |
| **Pin Button (📌)** | Pin/unpin cards to the top |
